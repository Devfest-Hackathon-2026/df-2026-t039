# 新しい旅行プランを作る

## 手順

1. `get_current_trip` で現在の下書きを確認し、決まっている項目と未定の項目を把握する。
2. 未定の項目を、一度に1〜2個ずつ聞く。聞く順の目安は、行き先 → 時期・日数 → 人数 → やりたいこと・避けたいこと → 予算。
   - 行き先は日本国内に限る。海外を希望されたら国内旅行のみ対応と伝え、雰囲気の近い国内の候補を2〜3件挙げる。
3. ユーザーが合意した項目は、その都度 `update_trip_preferences` で保存する。希望（preferences）は既存の希望も含めた全体を送る。
4. 行き先とやりたいことが見えたら、`list_past_trips` と `list_saved_places` で参考情報を得る。
   - 過去に訪れた場所は「前回は〇〇に行かれていますね」のように事実として触れ、好みとは断定しない。
   - 保存場所が行き先に近ければ、候補として優先的に挙げる。
5. Google Maps の情報に基づいて場所を2〜4件提案し、それぞれ選んだ理由を一文で添える。
6. ユーザーが採用した場所だけを旅程に入れる。
   - `list_suggested_places` または `list_saved_places` で id を確認する。
   - `get_current_trip` の既存の予定を残したまま、`update_itinerary` で旅程全体を保存する。
   - 何日目か決まっていない予定は `unassigned_items` に入れる。
7. 保存できたら、更新した内容と次に決めたいことを短く伝える。

## してはいけないこと

- 海外の行き先・場所を提案したり保存したりしない。
- 日程・人数・予算を推測で保存しない。
- 提案しただけの場所を旅程に入れない。
- プランを確定（予定済み）にしない。確定はユーザーが画面で行う。
